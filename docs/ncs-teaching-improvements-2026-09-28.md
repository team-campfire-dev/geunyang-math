## 설명을 바꾼 방식

### 계산 대상과 다음 행동을 분명하게

- “하루치를 더한 뒤 뒤집는다” → “각자의 하루 작업량을 더한 뒤, 남은 작업량을 하루 작업량으로 나눈다.” 전체 작업과 남은 작업의 계산을 구별한다.
- “두 값을 이으면 셋째 값이 나온다” → 회사 매출 80억 원과 점유율 10%로 시장 전체 매출 `80÷0.1=800억 원`을 구하는 과정을 설명한다.
- “추이·구성비” → 시간에 따른 변화, 전체에서 차지하는 비율을 먼저 설명하고 필요한 용어를 연결한다.
- “틀리는 원인은 계산이 아니라 단위” 같은 단정을 없애고 “분을 시간으로, 시속을 초속으로 바꾸기”처럼 배울 내용을 제목에 쓴다.

### 처음 배우는 계산에 중간 과정 추가

- 입문 통계는 평균·중앙값·범위에 집중한다. 가중평균과 표준편차의 자세한 계산은 후속 통계 수업으로 안내한다. 구거법은 추가 검산 방법으로 명시한다.
- 표준편차의 첫 계산은 `2,2,6,6 → 평균 4 → 차이 -2,-2,2,2 → 분산 4 → 표준편차 2`로 구성한다. 제곱과 제곱근의 뜻, 차이를 그냥 더하면 0이 되는 이유, 결과 해석을 설명한다.
- 복리는 1년 뒤 금액이 다음 해 계산 기준이 되는 과정을 먼저 보이고, 공식의 문자와 연 1회 이자 적용 조건을 설명한다.
- 농도가 다른 소금물을 섞는 예제를 확인 문제 전에 제공한다.

### 조건과 자료를 문항 안에 제공

- 정가만으로 이익을 묻던 문제에 실제 판매가와 다른 비용이 없다는 조건을 명시한다.
- 표 읽기·증감률·자료 비교·도표분석 예제는 사용하는 표를 같은 단계에 표시한다.
- 그래프 수업의 연습·확인 5문항에 실제 그림을 넣는다. 월별 값·축·단위를 표시하며, 누적 막대에서 B상품의 값은 `100−40=60`으로 구하게 한다.
- 업체 선택 연습은 가격·납기 표에서 두 조건을 적용하고, 확인 문제는 평가 점수 표에서 가중 총점을 계산해 업체를 고르게 한다.
- 빈도 드릴은 지문의 수를 그대로 옮기던 형태에서 원자료 `A,B,A,A,C,B,A`의 A 횟수를 세는 형태로 바꾼다.
- 도표 실습의 자료와 단위를 판매량으로 통일한다. 사용자가 조절할 수 있는 범위는 막대 높이이며 축·눈금·제목·단위는 주어진다는 것을 안내한다.

### 수학적 조건을 생략하지 않기

최빈값의 최고 빈도 조건, 중앙값을 선택하는 목적, 비중 합계가 100%가 되는 조건, 행·열 배치, 확률의 같은 가능성·독립 조건, 연 이자율과 기간, 작업 속도 일정 조건을 명시했다. 시험 출제 빈도와 시간 부족에 관한 출처 없는 단정도 제거했다.

## 판본과 기존 학습 기록

- 수업 21개와 문제집 67개에 새 판본을 추가했다. 지문·힌트가 바뀐 기존 229문항도 새 문항 판본으로 연결한다.
- 이전 문제집과 기존 발행 지문은 유지한다. `published-versions.json`의 기존 항목은 변경하지 않고 새 지문 88개를 추가한다.
- 풀이 해설은 발행 동결 대상이 아니다. 이전 문항 중 **지문과 채점이 새 문항과 동일한 경우에만** 해설을 보충했다. 답이나 조건이 바뀐 옛 문항에 새 해설을 붙이지 않는다.
- 이미 시작한 수업·배정된 복습은 기존 판본을 유지한다. 새 수업을 시작하거나 최신 문제집을 선택할 때 개정판이 적용된다. 사전은 배포의 `content:publish` 단계에서 갱신된다.
