# 학습 세션 읽기

2026-10-26 작성 · 브랜치 `feat/learner-sessions`

## 한 줄 요약

운영자가 편집 화면의 「학습 세션」에서 학습자 한 사람이 **언제, 어떤 기기로 들어와 무엇을 했는지**를 시간순으로 읽는다. 전에는 운영 DB를 직접 조회하고 nginx 접속 로그를 맞춰 봐야 알 수 있던 것이다(2026-10-25 첫 중학생 학습자의 세션을 그렇게 읽었다).

## 무엇을 보여 주는가

- **학습자 목록** — 마지막으로 학습한 때, 최근 30일 세션 수, 마친 수업, 답 수, 마지막으로 들어온 기기.
- **세션** — 30분 넘게 아무것도 하지 않으면 다음 세션으로 나눈다. 세션마다 시작–끝 시각(한국 시간), 들어온 기기, 그리고 한 줄씩:
  계정 만들기 · 로그인/페이지 열기/돌아오기/로그아웃 · 누가 과정을 정해 줬는지 · 수업 시작과 완료 · **단계마다 끝낸 시각과 걸린 시간** · 답(지문 앞부분, 낸 답, 맞음/틀림, 몇 번째인지, 힌트를 봤는지, 앞 동작에서 걸린 시간) · 힌트 · 과제가 생기고 제출됨 · 시작점 확인 · 의견 · 만들지 못한 AI 맞춤 연습.
- **세션에서 읽히는 것** — 줄을 다 읽지 않아도 보이게 위에 적는다.
  | 표시 | 언제 |
  |---|---|
  | 앱 안 브라우저 | 인스타그램·카카오톡 같은 앱 안에서 열었다. 로그인이 풀리기 쉽다 |
  | 다시 로그인 | 7일 안에 다른 로그인으로 들어온 적이 있는데 그 로그인에서 로그아웃하지 않았다 — 로그인이 풀렸거나 다른 브라우저다 |
  | 처음부터 다시 엶 | 한 세션에서 페이지를 3번 이상 새로 열었다 |
  | 넘김 | 읽기만 하는 단계(개념·함께 풀기)를 10초 안에 끝냈다 |
  | 여러 번 틀림 | 한 문제를 2번 이상 틀렸다 |
  | 힌트 | 힌트를 열었다 |
  | 깔끔함 | 답 3개 이상을 모두 한 번에, 힌트 없이 맞혔다 |
  | 멈춤 | 시작한 수업을 그 세션이 끝날 때까지 마치지 않았다 |

다른 사람이 학습자를 위해 한 일(과정 정해 주기)만 있는 구간은 「학습자 없이 있었던 일」로 따로 보인다.

## 새로 남기는 것

| 무엇 | 어디에 | 언제 쓰나 |
|---|---|---|
| 단계를 마친 시각 | `Enrollment.sectionTimes` (단계 id → 시각) | `section.complete` |
| 방문 | `LearnerVisit` | 로그인(Google 콜백), 학습 화면을 열 때(`GET /api/v1/session?visit=open`), 브라우저가 보관한 페이지로 돌아올 때(`?visit=return`), 로그아웃 |

방문에는 **종류만** 남긴다 — 기기(폰·태블릿·컴퓨터), 운영체제, 브라우저, 앱 안 브라우저라면 그 앱. 브라우저가 보내는 문자열 원문(폰 모델명이 들어 있다)과 IP는 저장하지 않는다. [개인정보 안내](../src/app/privacy/page.tsx)에 같은 내용을 적었다.

- 방문 기록을 쓰지 못해도 요청은 그대로 성공한다. 읽는 쪽 기록이지 학습에 필요한 기록이 아니기 때문이다.
- 한 페이지 열기가 두 번 들어오면 하나로 친다. 화면은 한 번 붙을 때 한 번만 알리고(React 개발 모드는 두 번 붙는다), 서버는 같은 로그인·같은 종류가 2초 안에 또 오면 버린다.
- 계정을 지우면 방문도 함께 지워진다(`onDelete: Cascade`). 세션 행은 로그아웃 때 지워지므로 방문은 `sessionId`를 관계 없이 문자열로만 든다.
- 이 기록이 생기기 전의 학습에는 단계 시각과 기기가 없다. 그 구간은 단계 줄이 빠지고 답과 수업 시작·완료만 보인다.

## 읽지 못하는 것

- **로그인하지 않은 채 연 페이지.** 로그인이 풀린 뒤 다시 로그인하려다 그만둔 경우(첫 학습자가 그랬다)는 누구인지 모르므로 남지 않는다. 다시 로그인하는 데 성공하면 「다시 로그인」으로 보인다.
- 풀이 보기. [학습 서비스](../src/server/learning-service.ts)가 「읽기이지 학습이 아니다」라며 일부러 남기지 않는다.
- 화면 안에서 단계 사이를 오간 것, 머문 시간, 스크롤.

## 누가 보는가

관리자(`admin`)만 본다. 이름과 학습자가 쓴 답이 그대로 나오기 때문이다. 교사는 지금처럼 [가르치는 관계](teaching.md)에서 이름과 정해 준 과정만 본다 — 교사에게 풀이를 보여 주는 일은 학습자 동의 방식을 먼저 정한 뒤다.
