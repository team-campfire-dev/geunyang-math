대화에서 만든 초기 기획·로드맵·검토 결과는 당시 의사결정의 기록이다. 최신 완료 여부는 구현 현황, 명령은 프로젝트 README와 각 운영 문서, 배포 결과는 릴리스 기록과 GitHub Actions를 기준으로 확인한다.

문서를 갱신할 때는 기능 검증 기준과 실제 실행 링크를 함께 남긴다. 운영 코드나 권한을 바꾸지 않은 문서 수정은 새 기능 검증으로 기록하지 않는다. 콘텐츠 수와 테스트 수는 해당 검증 시점의 값이며 이후 확대 시 갱신한다.
