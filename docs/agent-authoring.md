# AI 편집 통로

2026-10-22 작성 · 코드 기준: `feat/agent-authoring`

작성자가 편집 화면에서 **코드**를 만들어 AI에게 건네면, 그 AI가 작성자의 계정으로 수업 초안을 읽고 고치고 검토를 요청할 수 있다. 사람이 편집 화면에서 하는 일과 같은 동작을 같은 서버 코드로 하고, 이 통로가 더하는 것은 **울타리**뿐이다 — 어떤 동작에 닿는지, 발행을 맡겼는지, 저장이 어느 판의 초안 위에서 만들어졌는지.

## 쓰는 법

1. 편집 화면 → 「AI 연결」 → 이름(예: 「Claude 중2 수업 다듬기」)과 기간(1·7·30·90일)을 고르고 「코드 만들기」.
2. 나타난 글을 복사해 AI와의 대화에 붙인다. 코드와 API 주소, 첫 호출이 들어 있다. **코드는 이때 한 번만 보인다.** 잃어버리면 거두고 새로 만든다.
3. AI는 `GET /api/v1/agent`로 안내를 읽고 시작한다. 고친 초안은 편집 화면의 초안 목록에 내 이름으로 보이고, 검토 요청이면 「검토 요청」 상태다.
4. 다 쓰면 「거두기」. 그 순간부터 코드는 401이다.

## 무엇을 할 수 있나

코드는 **만든 계정보다 더 할 수 없다.** 역할은 호출마다 다시 읽으므로, 계정이 편집 권한을 잃으면 코드도 바로 403이다.

| 동작 | 발행하지 않는 코드 | 발행을 맡긴 코드 |
|---|---|---|
| `lesson.read` `problemSet.read` `definition.list` `problem.wrongAnswers` | ✓ | ✓ |
| `lesson.create` `draft.create` `draft.save` `draft.validate` `draft.review` | ✓ | ✓ |
| `draft.tryAnswer` `draft.openHint` | ✓ | ✓ |
| `draft.publish` `definition.save` | — | ✓ (계정이 관리자일 때만 만들 수 있다) |

`definition.save`가 발행 쪽에 있는 것은 뜻풀이에 판본이 없어서 저장이 곧 학습자에게 보이기 때문이다.

닿지 않는 것: 코스 정보·순서, 개념 추가, 시작점 확인(진단), 문제집 이름, 초안 삭제(누군가의 작업일 수 있다), 역할과 계정 검색, 편집 화면 설정, 「AI로 문제 만들기」(건너편이 이미 모델이고, 이 서비스의 예산을 쓰게 된다).

## API

모든 요청에 `Authorization: Bearer gmk_…`. 쿠키도 Origin 검사도 없다 — 브라우저가 스스로 붙이는 값이 아니므로 다른 사이트가 대신 보낼 수 없다.

| 요청 | 돌려주는 것 |
|---|---|
| `GET /api/v1/agent` | `guide`: 이 코드의 계정·역할·발행 여부·만료, 작업 순서와 규칙, 동작마다 설명과 JSON Schema, 쓸 수 있는 블록마다 예시와 payload JSON Schema, [작성 지침](lesson-writing-guide.md)의 「지침」 전문 |
| `GET /api/v1/agent?view=workspace` | 편집 화면의 목록에서 역할·설정을 뺀 것 |
| `GET /api/v1/agent?draftId=…` | 초안 하나. `draft.edit`가 저장할 때 보내는 형태 그대로다 |
| `POST /api/v1/agent` | 편집 화면과 같은 `{ "action": … }` 본문. 응답은 그 동작의 결과에서 `workspace`를 뺀 것 |

**`draft.save`는 `baseUpdatedAt`을 요구한다** — 마지막으로 읽은 초안의 `updatedAt`. 그 사이 초안이 바뀌었으면(사람이 편집 화면에서 저장했으면) `409 draft_changed`로 거절하고 아무것도 쓰지 않는다. 편집 화면 쪽은 이 검사를 하지 않으므로, 사람이 같은 초안을 열어 둔 채 자동 저장하면 AI가 쓴 것을 덮을 수 있다. 같은 초안을 AI와 사람이 동시에 만지지 않는 것이 안전하다.

본문 상한은 편집 화면과 같은 256KB다. 동작마다 `agent_action` 로그(`keyId`·`userId`·`action`)를 남긴다.

## 저장

`AgentKey` 표(`20261022000000_agent_key`). 코드 자체는 저장하지 않고 SHA-256 해시와 앞 10글자(`gmk_` + 6)만 둔다. 마지막 사용 시각은 1분 단위로 적는다. 한 계정에 10개까지이고, 기간이 지난 코드는 주인이 목록을 볼 때 지운다. 계정을 지우면 함께 지워진다.

## 아직 없는 것

- 호출 횟수 제한. 지금은 계정의 편집 권한과 코드 만료·거두기가 전부다.
- 편집 화면의 자동 저장이 AI의 저장을 알아차리는 것(위의 덮어쓰기).
- 진단·코스·뜻풀이 편집을 발행하지 않는 코드로 하는 길. 뜻풀이에 초안이 생기면 발행 쪽에서 내려올 수 있다.
